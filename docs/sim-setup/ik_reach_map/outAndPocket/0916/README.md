# 2026-09-16 実験: 試行を繰り返した成功率と、ポケット0.9倍の効果

## 先に1点

**`pocket_reach_by_distance.png`（格子版）は乱数を使っていません。** 格子点の座標も IK も決定論的なので、
何度実行しても同じ結果になります。ばらつきが出るのは**ランダムサンプリング**の方なので、
そちらを**シードを変えて3回**回し、成功率の振れ幅を測りました。

## 結果: ポケットを 0.9 倍にすると成功率 +0.92 ポイント

ランダム2000点（ZED画角内 / pelvis から前方 0.05〜0.65 m）× 3シード。

| ポケット | 外形 | 成功率（平均 ± 標準偏差） | 各試行 |
|---|---|---|---|
| 従来 | 8.0 × 17.0 × 8.5 cm | **18.78 % ± 0.28** | 18.65 / 19.10 / 18.60 |
| **0.9倍** | **7.2 × 15.3 × 7.7 cm** | **19.70 % ± 0.39** | 19.45 / 20.15 / 19.50 |
| 差 | | **+0.92 ポイント** | |

**シード間のばらつき（±0.4以下）より差（+0.92）が大きい**ので、この差は乱数のゆらぎでは説明できません。
同じ点群での対応比較でも、3シードすべてで +16 / +21 / +18 点と一貫して改善しています。

格子版（1000点・決定論的）でも 207 → **219 点**（+12）と同じ向きの結果でした。

## ただし効果は限定的。理由が重要

**ポケットに当たる点は 66〜84 点減ったのに、到達できる点は 16〜21 点しか増えていません。**

| 状態（3試行平均） | 従来 | 0.9倍 | 差 |
|---|---|---|---|
| 到達できる | 376 | **394** | **+18** |
| ポケットに当たる | 502 | **427** | **-75** |
| モデル干渉・姿勢が再現できない | 497 | **554** | **+57** |
| IK が解けない | 303 | 303 | 0 |
| ワークスペース箱の外 | 323 | 323 | 0 |

減った「ポケットに当たる」75点のうち、**57点は「モデル干渉」に移っただけ**です。
つまり**ポケットが無くても、その空間は元々自己干渉などで使えなかった**ということになります。

ポケットをさらに小さくしても、この頭打ちの構造は変わらないと考えられます。
到達範囲を実質的に広げたいなら、ポケットのサイズより**取り付け位置**（胸の中央を避ける等）の方が効く可能性があります。
※ これは今回のデータからの推測で、位置を変えた検証はしていません。

## 再現方法

```bash
# 0.9倍ポケットの生成
python3 /isaac-sim/workspace/sub/四次元ポケット_CAD/make_pocket_halfcylinder.py \
    --width 153 --depth 76.5 --extrude 72 --thick 2.7 \
    --out /isaac-sim/workspace/sub/四次元ポケット_CAD/pocket_halfcyl_09.stl

# ランダム試行（1条件1シード分）
cd /isaac-sim/workspace/DimOS_base_G1-TOYOTA-BODY-
T=/isaac-sim/workspace/02_orita_tool/IK_doc
.venv/bin/python $T/zed_fov_reach_map.py --random 2000 --rand-min 0.05 --rand-max 0.65 \
    --radius-center 0.00396,0,-0.044 --seed 0 --out <出力先>
conda run -n env_isaaclab_2 python $T/isaacSim/isaac_reach_verify.py \
    --csv <出力先>/reach_map.csv --out <出力先>/isaac_verify_with_pocket.csv \
    --pocket --pocket-origin 0.0709,0,0.0770 \
    --pocket-size 0.072,0.0765,0.0765 \
    --pocket-stl /isaac-sim/workspace/sub/四次元ポケット_CAD/pocket_halfcyl_09.stl

# 集計図
.venv/bin/python /isaac-sim/workspace/02_orita_tool/IK_doc/outAndPocket/0916/plot_trials.py
```

`--pocket-size` は「奥行き, 左右半径, 深さ[m]」。**ポケットを変えたらここも必ず合わせること**
（形状ファイルだけ変えても判定は変わりません）。

## 断定できないこと

- ポケット判定は**外形ボリュームに腕の点が入るか**で見ている安全側の評価。
  ポケットの中に手が入る状態も当たりと数えるので、実際にはもう少し余地がある可能性がある。
- 自己干渉の大半はめり込み1mm未満（convex hull のかすり）。この成功率は**保守的な下限**。
- 3シードしか回していないので、標準偏差の推定は粗い。差の向きは3シードとも一致しているが、
  厳密な有意差検定はしていない。
- 骨盤固定・重力0。**バランスと重力たわみは見ていない。**
